# SmartHire 360

AI-Powered Intelligent Recruitment & Workforce Analytics Platform

## Features

- AI Resume Screening
- Resume Classification
- Candidate Ranking
- Salary Prediction
- Employee Retention Prediction
- HR Analytics Dashboard
- AI Skill Extraction

## Technologies Used

- Python
- Flask
- MongoDB Atlas
- Machine Learning
- NLP
- HTML/CSS/Bootstrap
- JavaScript

## Run Project

```bash
pip install -r requirements.txt
python app.py
```
